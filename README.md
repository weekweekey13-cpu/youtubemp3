# YouTube → MP3 Telegram-бот

Бот: [@dowloadmp3youtube_mp3bot](https://t.me/dowloadmp3youtube_mp3bot)

Кидаешь ссылку на YouTube — получаешь MP3. Перед скачиванием пользователь должен быть подписан на каналы, которые задаёт админ.

Админ: `@bonamartin69` (`/admin`)

- добавить / убрать каналы для обязательной подписки
- кнопки «Подписаться» ведут в эти каналы
- рестарт бота

## Render

`BOT_TOKEN` задаётся только в Environment Variables, в репозиторий не кладётся.

Чтобы бот не засыпал на бесплатном плане — UptimeRobot раз в 5 минут на `https://СЕРВИС.onrender.com/health`.
